# Handwritten Digit Recognition Using Deep Learning

## Project Overview
This project focuses on building an intelligent Handwritten Digit Recognition System using Machine Learning and Deep Learning techniques. The model is trained on the MNIST dataset to accurately identify handwritten digits from 0–9.
The project demonstrates the implementation of image preprocessing, data visualization, machine learning algorithms, and Convolutional Neural Networks (CNNs) for image classification tasks.

---
## Business Problem
Handwritten digit recognition is one of the most important applications of Computer Vision and Optical Character Recognition (OCR). Manual identification of handwritten numbers is time-consuming and error-prone.

The goal of this project is to automate digit recognition with high accuracy using Deep Learning models.

---
## Dataset Information

* Dataset: MNIST Handwritten Digits Dataset
* Total Images: 70,000
* Training Images: 60,000
* Testing Images: 10,000
* Image Size: 28x28 pixels
* Output Classes: Digits (0–9)
